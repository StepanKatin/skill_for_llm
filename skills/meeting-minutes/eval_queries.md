# Eval queries for `meeting-minutes`

Критерии: 6 запросов должны выбирать скил, 4 — нет.

## Должны триггерить скил (6)

1. **«Сделай протокол встречи из этих заметок: обсудили API, Иван до пятницы готовит черновик»**  
   Явный запрос протокола встречи + заметки с задачей — ядро сценария скила.

2. **«Оформи meeting notes: были PM, разработчик и QA, решили перенести релиз»**  
   Meeting notes + решения совещания — прямое попадание в description.

3. **«Вытащи action items из совещания по этапам проекта и укажи ответственных»**  
   Action items / этапы проекта / ответственные — формулировка из продуктового сценария.

4. **«Нужен саммари собрания по ролям: что решили, какие задачи кому поставили»**  
   Саммари собрания + роли + задачи — классический триггер.

5. **«Преврати черновик совещания в структурированный протокол с таблицей задач и сроками»**  
   Прямо описан целевой артефакт скила.

6. **«Подготовь итоги стендапа: решения и задачи со сроками для выгрузки в Word»**  
   Итоги встречи + задачи/сроки + выгрузка — релевантно даже без слова «протокол».

## Не должны триггерить скил (4)

7. **«Переведи этот текст на английский»**  
   Перевод без контекста встречи — в description явный anti-trigger.

8. **«Что такое Clean Architecture?»**  
   Общий вопрос, не связанный с заметками/совещанием.

9. **«Просто структурируй этот абзац списками»**  
   Просьба структурировать текст вне контекста встречи — исключено description.

10. **«Кратко перескажи статью про микросервисы»**  
   Пересказ статьи, не протокол совещания.

## Пример: заметки → протокол

### Вход (заметки)

```
Совещание 18.03.2026. Участники: Анна (PM), Борис (backend), Кира (QA).

Анна: нужно зафиксировать этапы. Сначала контракт API, потом интеграция, затем регрессия.
Борис: контракт API могу закрыть до 20.03, OpenAPI черновик уже есть.
Кира: тест-план на интеграцию подготовлю после контракта, срок пока неясен.
Решили: не двигаем дату релиза; Борис делает OpenAPI; Кира готовит тест-план.
Ещё попросили Анну обновить статус в Jira — исполнителя назвали, срок нет.
```

### Выход (формат скила)

```
# Протокол встречи

## Метаданные
- Дата: 18.03.2026
- Участники: Анна (PM), Борис (backend), Кира (QA)

## Обсуждение
Обсудили этапы проекта: контракт API, интеграция, регрессия. Подтвердили наличие черновика OpenAPI у backend. QA ожидает контракт перед подготовкой тест-плана. Дату релиза сохраняют.

## Решения
1. Не двигать дату релиза.
2. Борису подготовить OpenAPI-контракт.
3. Кире подготовить тест-план после готовности контракта.
4. Анне обновить статус в Jira.

## Задачи
| Задача | Ответственный | Срок |
|--------|---------------|------|
| Подготовить OpenAPI-контракт API | Борис | 20.03 |
| Подготовить тест-план на интеграцию | Кира | Не указан |
| Обновить статус в Jira | Анна | Не указан |
```
