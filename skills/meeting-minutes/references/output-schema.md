# Схема выходного протокола

Вынесено из тела `SKILL.md`, чтобы не раздувать системный промпт.
Конвертер Word ожидает эти секции дословно, без эвристик.

## Секции (порядок фиксирован)

1. `# Протокол встречи`
2. `## Метаданные` — `Дата`, `Участники`
3. `## Обсуждение`
4. `## Решения`
5. `## Задачи` — таблица `Задача | Ответственный | Срок`

## Плейсхолдеры

- нет ответственного / срока → `Не указан`
- пустой раздел → `Нет данных`
